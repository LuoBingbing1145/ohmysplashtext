## ✨ Introduction  

**OhMySplashText** is a **Fabric** client-side mod that lets you customize the Splash Text on the Minecraft main menu. Features include:  
- ✅ Customizable text content  
- 🎨 Color and font size control  
- 🔄 Adjustable rotation angle  
- 📈 Use math expressions to animate properties like position and rotation over time — with real-time preview support  

## 🌍 Language Support  

Currently available in:  
- Simplified Chinese `zh_cn`  
- English `en_us`  

You're welcome to contribute translations for other languages!  

## 🛠️ Version Support & Update Plan  

- This mod supports **Minecraft Fabric 1.20 and above**  
- The following versions are **prioritized for updates**:  
  - Latest official release
  - **1.20.1** (a widely used popular version)
- Other versions (e.g., 1.20.2~1.20.4) will be **supported as needed**, *with no guarantee of simultaneous updates*

Please download it from the GitHub Releases page: Releases

## ❓ FAQ  

### Q: Will **1.19** or earlier versions be supported?  
A: **No**. Only **1.20 and later** are maintained. *There are no plans for backward compatibility*.

### Q: Will this mod be ported to **Forge**?
A: **Not planned**. This is the author's first mod, and they are currently only familiar with the **Fabric** ecosystem. Thank you for your understanding.

### Q: How do I write animated functions?
A: You can use the **built-in Function Preview Screen** to test animations in real time. The mod also includes **function templates**, making it easy to get started even if you're unfamiliar with math expressions.  
*Note: This feature is still experimental — feel free to report issues!*
